# noah_bin_unpacker
诺亚舟bin词典格式文件提取器
<img width="1115" height="628" alt="image" src="https://github.com/user-attachments/assets/2b04ebc8-a046-4a33-9124-a5757ae4350e" /><img width="1076" height="779" alt="image" src="https://github.com/user-attachments/assets/eddba160-9b5f-472e-b155-ccbdcf02b5e5" />

此脚本可以将诺亚舟特有的bin格式文件进行解压操作，以便进行研究或再修改。
注：因诺亚舟对bin文件的使用没有明确标准，目前只针对NP1500的动漫词典和诺亚词霸（汉）进行了测试，如发现有部分文件无法打开请反馈给我。
